# 🌿 GreenRoute - Système d'Intelligence Artificielle\n\n## 📋 À Propos du Projet\n\n**GreenRoute** est [À COMPLÉTER APRÈS LECTURE DES DOCS DU PROJET]\n\nCe projet combine:\n- 🤖 Intelligence Artificielle/Machine Learning\n- 🌐 API Web (FastAPI/Flask)\n- 🎨 Interface Utilisateur (Streamlit/Dash)\n- 📊 Monitoring et Alertes\n- 🔒 Sécurité et Scalabilité\n\n---\n\n## 🚀 Quick Start\n\n### Prérequis\n- Python 3.9+\n- pip ou conda\n- Git\n\n### Installation (5 minutes)\n\n```bash\n# 1. Cloner le repository (si sur GitHub)\ngit clone https://github.com/YOUR_USERNAME/greenroute.git\ncd greenroute\n\n# 2. Créer l'environnement virtuel\npython -m venv venv\n\n# 3. Activer l'environnement\n# Windows:\nvenv\\Scripts\\activate\n# MacOS/Linux:\nsource venv/bin/activate\n\n# 4. Installer les dépendances\npip install -r requirements.txt\n\n# 5. Créer le fichier .env\ncp .env.example .env\n# Éditer .env si nécessaire\n```\n\n### Lancer l'Application\n\n```bash\n# Option A: Lancer l'API\nuvicorn src.api.main:app --reload --port 8000\n# API disponible à: http://localhost:8000\n# Swagger UI: http://localhost:8000/docs\n\n# Option B: Lancer le Frontend (dans un autre terminal)\nstreamlit run src/frontend/app.py\n# Frontend disponible à: http://localhost:8501\n\n# Option C: Lancer les deux ensemble\n# Terminal 1:\nuvicorn src.api.main:app --reload\n# Terminal 2:\nstreamlit run src/frontend/app.py\n```\n\n### Lancer les Tests\n\n```bash\n# Tous les tests\npytest tests/\n\n# Tests avec coverage\npytest tests/ --cov=src\n\n# Fichier spécifique\npytest tests/test_models.py\n\n# Verbose output\npytest tests/ -v\n```\n\n---\n\n## 📁 Structure du Projet\n\n```\ngreenroute/\n├── src/                    # Code source principal\n│   ├── data/               # Chargement et préparation des données\n│   ├──
